# High-Frequency Market Making from First Principles

This repository contains the LaTeX source for a theoretical paper on high-frequency market making.
The paper develops price dynamics, valuation inference, and trading controls from discrete trade arrivals.
It distinguishes the risk between pricing fluctuations in statistically admissible regimes and model failure
regimes. It also analyzes Bayesian inference for market making's continous qouting, and introduces a mechanisms
for handling each of the distictive risk regimes.

## Files
- `main.tex` — main LaTeX source
- `references.bib` — bibliography
